# 离线 HTML 渲染规范

- 从 `chapter-XX-zh.json` 渲染真实、可搜索、可复制的中文文本。
- 分页和连续模式并存；逻辑段落优先于 PDF 页边界。
- 跨页段落保持单个 DOM 段落，页码用段内 `.page-anchor`。
- 图片与图注位于完整段落后且不分离。
- 注释采用原位可访问 popover，文末无重复列表。
- 中文、英文括注、图注和注释统一正常字形；禁止 `<em>`、`<i>` 或有效 italic CSS。
- 不依赖 CDN；不引用临时或绝对路径；长单词和网址可换行。
- 支持 1366×768、1920×1080 和 390×844，无横向溢出。
