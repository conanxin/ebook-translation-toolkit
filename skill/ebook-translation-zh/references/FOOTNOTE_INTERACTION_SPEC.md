# HTML 原位注释交互规范

- 正文注释使用真实 button，包含 `aria-expanded`、`aria-controls`、可见焦点和键盘触发。
- 注释内容保存在不可见 template 中；打开时复制到当前位置附近 `role="note"` 的卡片。
- 再次点击同一按钮、点击外部、关闭按钮或 Escape 均关闭；Escape 还原焦点。
- 展开状态的按钮必须位于注释卡片之上，确保桌面与移动端底部卡片模式下都能实际再次点击同一按钮关闭。
- 卡片内容可选择、复制，长网址换行，移动端宽度不超过视口。移动端 CSS 必须用 `width:auto !important` 覆盖桌面定位留下的内联宽度，确保切换视口后仍不越界。
- 不改变 URL、不跳转、不在文末重复列注释。
- 编号从 1 连续递增，引用与定义一一对应。
- 组件完全离线，不使用 CDN 或外部脚本。
