# PDF 结构提取规范

- 逐页记录尺寸、文本、文本块、坐标、字体、字号、粗斜体语义、阅读顺序、标题、图片与表格。
- 原生文字层可靠时禁止重复 OCR；可靠性检查至少覆盖字符量、替换字符和字母比例。
- 仅对不可靠页面调用 OCR，并在结构报告中记录页码与工具。
- 页眉、页脚、页码和装饰性元素必须与正文区分。
- 多栏页面先按栏再按纵向排序；异常顺序必须支持人工覆盖。
- `ebook-pages.jsonl` 每页一个对象；`ebook-fulltext.md` 保留页码标记；`ebook-structure.json` 保存目录和章节范围。
- 所有坐标使用 PDF 页面坐标系，保留宽高，以便图像裁切和版式重建。
- 尾注标记消歧必须排除图号、小数版本号和许可证版本号（例如 `Share Alike 2.5 Generic License`），同时保留年份后紧接真实注号等合法情形。
