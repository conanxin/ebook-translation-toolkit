# 段落与分页规则

- PDF 页面边界默认不产生新段落。
- 前页末尾没有终止标点、后页以小写字母或连续从句开头时合并。
- 前页已有终止标点且后页以大写介词或连接词（例如句首 `In`）起始时，不得仅因词形匹配而自动合并。
- 页眉、页脚、页码、图片和脚注标记造成的伪断段必须消除。
- 分栏切换先恢复真实阅读顺序，再判断段落。
- 跨页锚点保存字符偏移和所在 block_id；HTML 不创建新 `<p>`，Markdown 不插入空段。
- `paragraph-overrides.yaml` 可强制 merge/split/retype/replace；split 可用 `left_type`、`right_type` 保留小节标题与随后正文的独立语义，并须正确重算两侧页码范围和段内锚点；replace 仅用于经 PDF 核实的断词或字符映射修复；输入 ID 必须来自原始块。
- 多章节项目的书籍特例应写入 `chapters.<章号>`；章节级指令不得泄漏到具有相同块 ID 的其他章节。
- 每次规范化从原始页数据重建，确保幂等。
- 不得用中文流畅度作为合并两个独立英文段落的理由。
