# 图片位置规则

- 图片只能位于完整段落、标题或独立图版之后，不能插入未结束段落。
- 默认锚定到图片之前最近的完整相关段落；语义优先于机械页码邻近。
- 每幅图片只渲染一次，保留 PDF 页码、坐标、英文/中文图注和 SHA-256。
- 原始资产不得重编码；项目、HTML、Markdown、Vault 使用同一文件哈希。
- `image-overrides.yaml` 用 image_id 指定 after_block_id。
- 图注与图片组成不可分离的 figure，窄屏不得横向溢出。
- 同一图号由多个 PDF 内嵌图像对象组成时，按这些对象的联合真实边界生成高分辨率组合裁切，保持原版面板关系；不得把各面板当作重复图号分别渲染。
- PDF 粗粒度文本块把 `A B` 等短面板标签置于 `Figure N.N` 图注之前时，仍须识别为该图图注，并保留面板标签与组合关系。
