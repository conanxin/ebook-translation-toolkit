ebook-translation-toolkit

v0.2.0 · github.com/conanxin/ebook-translation-toolkit · MIT

Structure-first PDF ebook translation pipeline for Chinese HTML, Markdown, Obsidian, and reflowable EPUB 3. One PDF → structured chapter JSON → HTML + Markdown + Obsidian + EPUB 3, all from a single source of truth.

What it does

PDF → structured JSON
Text-layer detection, OCR fallback, cross-page paragraph repair.
Translation packets
One block per logical paragraph. Stable block_id.
Terminology lock
Project-level preferred_zh / deprecated_zh.
Footnotes
Inline popovers, standard [^N] in Markdown, EPUB 3 <aside>.
Obsidian sync
Name-safe notes, [[wikilinks]], image copies.
EPUB 3 deterministic
reflowable, no JS, byte-identical consecutive builds.

Architecture

PDF
  → extract
  → detect chapters
  → normalize paragraphs
  → translation packets
  → translate / review
  → structured chapter JSON
  → HTML | Markdown | Obsidian | EPUB 3
  → QA / regression / reproducibility

Quick start

PowerShell

git clone https://github.com/conanxin/ebook-translation-toolkit
cd ebook-translation-toolkit
pip install -e ".[test]"
pip install PyMuPDF PyYAML Jinja2 beautifulsoup4

& scripts/ebook-translate.ps1 init     -Pdf "<PDF>" -ProjectRoot "<PROJECT_ROOT>"
& scripts/ebook-translate.ps1 render-epub -ProjectRoot "<PROJECT_ROOT>"
& scripts/ebook-translate.ps1 validate-epub -Epub "<PROJECT_ROOT>\output\epub\<slug>-zh.epub"

Bash / WSL

git clone https://github.com/conanxin/ebook-translation-toolkit
cd ebook-translation-toolkit
pip install -e ".[test]"
pip install PyMuPDF PyYAML Jinja2 beautifulsoup4

scripts/ebook-translate.sh init     --pdf <PDF> --project-root <PROJECT_ROOT>
scripts/ebook-translate.sh render-epub --project-root <PROJECT_ROOT>
scripts/ebook-translate.sh validate-epub --epub <PROJECT_ROOT>/output/epub/<slug>-zh.epub
